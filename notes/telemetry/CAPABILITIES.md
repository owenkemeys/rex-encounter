# Host capabilities available to the published page (runtime contract 0.2.96), as described by the host

General: capability namespaces live behind `claude.use(name)`: `const db = await claude.use("db")` resolves the namespace, or `null` when this view cannot run it (not served, not granted, failed to load: indistinguishable). Branch on `null` and design for absence. `window.claude` carries only `use`; never read `window.claude.db` etc. The promise resolves later (never within the script's first run; `null` after 10 s when no viewer answers). The resolved namespace is frozen: call its functions, keep the reference, never assign to it. Permission stays on the calls: a consent prompt, rate limit or refusal arrives on the first call, never from `use()`. Awaiting `use("db")` again is free. `window.claude` may not exist at all outside the host (local headless runs): guard `window.claude && window.claude.use`.

## db
`db` keeps data outside the page: shared rows, per-person state, data Claude reads. Declared as `capabilities:{db:{},user:{}}` (the director declares it on the artifact; you do not). `const db = await claude.use("db")` (`null` if signed out). By default signed-in people read shared docs, Contributors and up overwrite/delete, Viewers never write. `data/users/<id>/` is private even from the owner; `<id>` = `await user.id()` (from `claude.use("user")`). Even segment counts are docs (`db.doc("tasks/t1")`), odd are collections; `db.collection("sessions").doc(k)`; methods: get/set/update/delete, where/orderBy/limit, onSnapshot. Handle an empty db. Time-limit loading (10 s timer). One write at a time per doc, only on change. No secrets.
The director (Claude) reads the data afterwards with host tools that list/query a collection: each document comes back with id, data, version, updatedAt; a document that is too large comes back without data, so keep each document small (aim well under 100 kB; split long sessions into numbered chunk documents).

## dictation
`dictation` turns the viewer's speech into text: `const d = await claude.use("dictation")` (`null` outside a Chromium browser tab and the desktop app: so NOT available in iPhone Safari; hide the mic there and offer typing). Call `d.start()` straight from the viewer's click or key press (nothing awaited before it) and catch its promise; the first start asks the viewer once. `d.onPartial(({text}) => ...)` live guess replacing the last; `d.onFinal(({text}) => ...)` settled phrase to append; `d.onState(({state, reason}) => ...)` ("listening" until back to "idle" with a reason like `stopped`, `viewer_stopped`, `hidden`). `await d.stop()` waits for the last words. `start()` rejected `not_granted`: the viewer said no, do not ask again; `dismissed` may be retried on a later click.

## Host frame rules that matter here
Only the page's own files and data:/blob: load; fetch/XHR/WebSocket to other hosts are blocked; downloads and clipboard reads are refused; `navigator.clipboard.writeText` works only from a click handler and may be refused; localStorage may be missing or throw.
